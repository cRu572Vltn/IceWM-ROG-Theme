# About this theme
I based the look and feel of this theme on the classic ROG theme for Windows 7. I would love to leave a link to the original, sadly it seems to be indexed only on junk AI sites, you can search "Windows 7 ROG theme" yourself. Anyway, I missed the look my PC had in 2012/13, so I recreated the theme, removing the things I never liked (like the black edges of the taskbar).
